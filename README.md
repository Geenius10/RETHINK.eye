# EyeTrainer

Standalone PWA ohne externe Bibliotheken.

- 12 Übungsfamilien; ruhige Augenübungen ohne künstliche Level.
- Messbare Aufgaben enden nach einer festen Anzahl Trials bzw. einer festen Zeit, auch bei Fehlern oder ausbleibender Antwort.
- Ergebnisse und adaptive Level werden lokal gespeichert.
- iPhone und iPad: Hoch- und Querformat nutzen die verfügbare Fläche; auf großen Querformaten liegt die Bedienung rechts neben der großen Trainingsfläche.
- Sakkaden/Pursuit ohne Hilfslinien; Fixierung + Kopfbewegung ohne Kopf-Grafik.
- Motion Prediction nur als bewegte Verdeckung oder statische Extrapolation.
